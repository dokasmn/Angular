## :closed_book: Sobre o Projeto
Trata-se da emulação de um e-commerce desenvolvido por fins de aprendizado da framework Angular. Foi utilizado para o projeto o `Angular`, `Tailwind` e a api `***`.

## :clipboard: Pré-requisitos
  Para a implementação do sistema, você deve possuir esses recursos instalados na sua máquina

  *  git;
  *  Node Js;
  *  Npm;
  *  [Angular CLI](https://github.com/angular/angular-cli) version 18.2.4.

  ### Dependências do Projeto:

  Frontend: [Package.json](frontend/package.json)


## Para executar localmente
  *  clonar o repositório: executar em linha de comando `git clone "https://github.com/dokasmn/Angular"`;
  *  executar o comando `ng serve` para iniciar a aplicação na rota `http://localhost:4200/`.
